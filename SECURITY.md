# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/MttJns/re-dash/security/advisories/new)
rather than opening a public issue.

Include what you found, how to reproduce it, and the impact you expect. You'll get
an acknowledgement, and a fix or explanation once it has been investigated.

## Scope

- This repository's code, GitHub Actions workflow, and CloudFormation templates
- The deployed site at https://re-dash.com

The market data shown on the site comes from third-party public sources (Redfin,
Zillow, FRED, U.S. Census Bureau); issues with that data itself should go to those
providers.
